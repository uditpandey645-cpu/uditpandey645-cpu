### 🐍 Contribution Snake

<div align="center">
<img src="https://raw.githubusercontent.com/uditpandey645-cpu/uditpandey645-cpu/output/github-contribution-grid-snake-dark.svg" alt="contribution snake animation"/>
</div>

> The snake animates your commit history eating its way across your contribution graph — it's one of the most eye-catching things you can add. It needs a **one-time setup** (a GitHub Action that generates the SVG). Steps are below.

<details>
<summary><b>⚙️ How to enable the snake animation (one-time, ~2 min)</b></summary>

1. In your `uditpandey645-cpu/uditpandey645-cpu` repo, create the file `.github/workflows/snake.yml` (provided alongside this README).
2. Commit and push it to `main`.
3. Go to the **Actions** tab → run the `generate-snake` workflow once manually (or wait for the daily schedule).
4. It will automatically create and push an `output` branch containing the SVG — the image link above will then start working.
5. No further maintenance needed; it regenerates daily on its own.

</details>
